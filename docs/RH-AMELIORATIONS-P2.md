# RH — Améliorations phase 2 (P2)

> Document de référence pour les évolutions **hors MVP**.  
> Les éléments P0 et P1 sont implémentés dans le code ; ce fichier recense le reste.

---

## Formations

- Catalogue de formations (sécurité, incendie, premiers secours…)
- Historique par agent (dates, certificats, échéances)
- Alertes renouvellement de certification
- Lien avec les postes / sites (habilitations requises)

## Évaluations & entretiens

- Campagnes d’évaluation annuelle ou semestrielle
- Grilles de compétences par grade
- Entretiens professionnels (compte-rendu, objectifs)
- Historique sur la fiche agent

## Discipline & sanctions

- Dossier disciplinaire (avertissement, blâme, mise à pied)
- Lien avec le statut agent `suspendu`
- Traçabilité et pièces jointes

## Onboarding / offboarding

- Checklist d’embauche (documents, équipement, accès)
- Checklist de départ (restitution, solde de tout compte)
- Workflow guidé avec responsables

## Self-service agent (mobile / terrain)

- Demande de congé par l’agent
- Consultation du contrat actif et des bulletins
- Notification push des validations RH

## Déclarations sociales & CNPS

- Cotisations patronales
- Déclarations mensuelles / trimestrielles CNPS
- Export réglementaire

## Paie avancée

- Virements bancaires groupés (fichier SEPA / format local)
- Primes exceptionnelles hors bulletin
- Acomptes et avances sur salaire
- Régularisations multi-périodes

## Absences avancées

- Demi-journées et créneaux horaires
- Justificatifs médicaux (upload + validation)
- Workflow multi-niveaux (N+1 puis RH)

## Contrats avancés

- Signature électronique
- Modèles de contrat paramétrables par type
- Renouvellement automatique CDD (alerte + proposition)

## Organigramme & structure

- Services / départements
- Manager hiérarchique (N+1)
- Organigramme visuel

## Audit & conformité RH

- Journal dédié RH (qui a modifié salaire, contrat, absence)
- Export pour contrôle URSSAF / inspection du travail (adapté CI)
- Archivage légal des bulletins (durée de conservation)

## Notifications avancées

- E-mail et SMS (en plus des notifications in-app)
- Rappels configurables par type d’alerte
- Digest hebdomadaire RH

## Intégrations

- Export vers logiciel comptable
- Badgeuse / pointeuse (heures réelles vs planifiées)
- SIRH externe (si migration partielle)
